# Security

Kid Space runs with the Accessibility permission and stands between a child and the rest of a parent's phone. Security reports are welcome.

## What to report

- Any way to leave Kid mode, or reach an app that was not allowed, without the parent PIN.
- Any way to read or bypass the PIN.
- Any case where the app sends or exposes data. It should never do either; it has no internet permission.

## How to report

Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for these.

Please include your phone model, Android version, the Kid Space version, and the steps to reproduce. A screen recording helps a lot.

You should get a reply within 7 days. Fixes ship in the next release, and the report is credited in the changelog unless you ask otherwise.

## Supported versions

Only the latest release gets fixes.
